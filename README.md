# Tidewater Landing Page

GitHub Pages-ready static website.

## Files
- `index.html` — complete website with internal CSS

## GitHub Pages
1. Upload `index.html` to the root of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your `main` branch and `/ (root)`.
5. Save and wait for the deployment to finish.

The site uses no external CSS, JavaScript, or image files, so `index.html` is all that is required.
